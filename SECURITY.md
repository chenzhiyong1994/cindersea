# Security · 安全问题

Only the current public beta receives fixes. This is a small volunteer project; no response-time commitment is made.

If you find a vulnerability, **do not publish credentials, personal information, a weaponized exploit, or sensitive save files in a public issue**. Use a private contact method offered on the [maintainer's GitHub profile](https://github.com/chenzhiyong1994). If no private method is available, open an issue asking for a private reporting channel without disclosing sensitive details.

For ordinary gameplay bugs, use [Issues](https://github.com/chenzhiyong1994/dicebound/issues).

目前仅维护当前公开 Beta，项目不承诺固定响应时限。

发现安全问题时，**不要在公开 issue 中发布凭证、个人信息、可直接用于攻击的利用代码或敏感存档**。请使用[维护者 GitHub 主页](https://github.com/chenzhiyong1994)提供的私密联系方式；若暂未提供，可先发 issue 请求私密报告渠道，不披露敏感细节。

普通玩法缺陷请通过 [Issues](https://github.com/chenzhiyong1994/dicebound/issues) 反馈。
