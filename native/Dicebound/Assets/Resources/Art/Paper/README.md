# 纸本角色与场景原画

本目录保存战棋共享的六位人物肖像、六张场景原画和五种普通敌障原画。采用铜版线描、排线和不透明水粉表现，原画由项目使用内置 imagegen 制作。人物形象以维护者提供的正式设定为依据；文字、属性、按钮及选择状态在 Unity 中实时绘制。

| 目录 | 内容 |
| --- | --- |
| `Heroes/` | 司玄、凌风、沧泠、晏烛影、商朔与兼容保留的阮灼肖像 |
| `Scenes/` | 街巷、管廊、桥、档房、昼轮及行程结束场景 |
| `Enemies/` | 五种普通构装敌障 |

新旅程可选前五位同行者；资源存在不代表角色一定属于当前选人名单。战场动作使用 `Tactics/Sprites/` 的像素图集，本目录主要提供肖像与界面插画。

`generation-heroes.json` 与 `generation-scenes-enemies.json` 保留完整制作提示词、参考文件名、尺寸、输出路径及 SHA-256。公开版将原机器的绝对来源路径简化为原始文件名，不依赖制作机器，也不改动图像、提示词或哈希。生成记录中的历史创作语境不定义当前玩法。

这些图像不是商业参考游戏的提取文件。项目媒体不自动适用代码 MIT 许可，详见仓库根目录 `ASSET_NOTICES.md`。
