# 战棋界面素材

本目录包含项目生成的技能、资源、地形、旧物和路线图标，以及战斗边框和绘制皮肤。界面以墨玉底、古金描边和青玉交互色呈现；文字、数值、等级、状态及按钮逻辑由 Unity 实时绘制，不烘焙在概念图中。

`icons-layout.json` 与 `battle-v2-layout.json` 保存 PNG 左下角坐标系中的切片区域。图标按记录取样，九切皮肤用于边框；文字底由独立实色区域承托，避免细密底纹影响阅读。头像来自 `Art/Paper/Heroes/` 正式原画。

技能卡显示等级、简短用途和资源消耗；完整效果在相应详情中展示。技能选中、不可用和目标范围是运行时状态，不由固定图像决定。实际布局读取当前运行代码，素材原始规格不等于固定的屏幕控件尺寸。

本目录图像为项目 AI 辅助制作素材，没有导入商业参考游戏的角色、图标或场景。许可范围见根目录 `ASSET_NOTICES.md`。检查切片矩形和图片完整性不能替代 Player 的文字、状态和交互验收。
