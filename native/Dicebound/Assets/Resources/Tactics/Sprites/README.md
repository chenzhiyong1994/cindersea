# 战场像素图集

角色、普通构装敌障、三类独立精英及顶层首领均使用本项目制作的透明图集。同行者形象根据正式人设和项目立绘制作，不采用商业参考游戏的图像。

每张图集包含十二个姿态：待机、行走、出手各四帧。相邻的 `*-layout-v2.json` 记录明确的切帧区域与脚底锚点。运行时根据透明主体及这些区域隔离相邻动作，保留跨越名义格线的长兵器；PNG 原图不在加载时重绘。

图集以 Point、Clamp、无 mipmap、无压缩及可读 alpha 导入。项目 `Dicebound/TacticalSprite` Shader 处理显示；`TacticalActor` 管理帧与透明轮廓，`TacticalStage` 管理真实坐标和朝向。十二帧共用同一主体比例，脚底锚点落在棋格上。减少动态效果停止常驻循环。

资源中保留阮灼以支持已有角色数据，但新旅程可选名单仍为司玄、凌风、沧泠、晏烛影、商朔。图集存在不表示该角色可在新旅程选择。

生成素材不自动采用代码 MIT 许可，详见根目录 `ASSET_NOTICES.md`。切帧清单只能说明素材布局；实际动作、拾取、遮挡及显示仍需在 Unity Player 中验证。
